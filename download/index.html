First run

Up in a minute.

  1. 1Open the download and drag ILoveNotch into Applications.
  2. 2Open it. There's no Dock icon: look for the notch, and the ILoveNotch item in the menu bar.
  3. 3Quit any other notch app first; two apps can't share the notch.
  4. 4Hover the notch, click it, or press ⌃⌥O. Settings are in the gear, or the menu bar item.

From source

Build it yourself.

git clone --recurse-submodules \
  https://github.com/niyamvora/ILoveNotch.git
cd ILoveNotch
make setup   # XcodeGen and submodules
make run     # build and launch

Needs Xcode 16 or later and Homebrew.
